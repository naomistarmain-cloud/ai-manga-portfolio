# AI漫画 GitHub Pages公開用

このフォルダの中身をGitHubリポジトリにアップロードし、GitHub Pagesを有効にすると公開できます。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成
2. このフォルダ内のファイルとフォルダをリポジトリ直下へアップロード
3. リポジトリの Settings → Pages を開く
4. Sourceを Deploy from a branch にする
5. Branchを main、フォルダを /root にする
6. Saveする

公開URLの例:

```text
https://ユーザー名.github.io/リポジトリ名/
https://ユーザー名.github.io/リポジトリ名/03-restaurant-takeout/
```

Google Sitesには、トップページまたは各作品ページへのリンクを貼ってください。
